# Хвильовий алгоритм кластеризації везикул

Цей скрипт реалізує алгоритм хвильового фронту для прив'язки везикул до клітинних ядер на основі просторової близькості та готових сегментаційних масок.

## Підготовка даних

Для роботи скрипта потрібні вихідні дані (зображення та маски), які не включені у вихідний код.

1. Завантажте папку з даними `vizs`.
2. Розмістіть папку `vizs` у кореневій директорії проєкту, строго поруч із Python-скриптом.

Переконайтеся, що підсумкова структура файлів виглядає наступним чином:

    ваш_проєкт/
    ├── main.py            # Файл із вихідним кодом
    └── vizs/              # Завантажена папка з даними
        ├── images/        # Оригінальні зображення (.jpg)
        ├── npy/           # Файли instance-масок (.npy)
        └── semantic/      # Файли семантичних масок (.png)

Примітка: Переконайтеся, що у блоці `if __name__ == "__main__":` у файлі `main.py` змінна `base_dir` встановлена як `"vizs"`.

## Встановлення залежностей

Для роботи алгоритму потрібно встановити зовнішні бібліотеки. Використовуйте файл `requirements.txt`:

    pip install -r requirements.txt

## Запуск

Коли залежності встановлені, а папка `vizs` знаходиться у потрібному місці, запустіть скрипт із термінала:

    python main.py

За замовчуванням скрипт налаштований на обробку тестового зображення `db_img_0084`. Після успішного виконання розрахунків відкриється вікно з фінальною візуалізацією: оригінальне зображення з колірною індикацією кластерів везикул та червоними контурами клітинних ядер.
