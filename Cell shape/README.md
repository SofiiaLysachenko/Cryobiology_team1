# Класифікація форм клітин

Цей скрипт призначений для аналізу сегментаційних масок клітин (у форматі .npy). Він розраховує морфологічні метрики кожної клітини (площа, периметр, ексцентриситет, солідність тощо) та класифікує їх за формою, після чого візуалізує результат, накладаючи кольорові контури на оригінальне зображення.

## Можливості та класифікація

Алгоритм виділяє наступні форми клітин, кожній з яких відповідає свій колір на підсумковій візуалізації:

* Round (Круглі) — Червоний контур
* Spindle-shaped (Веретеноподібні) — Зелений контур
* Multi-branched (Багатогалузеві / розгалужені) — Синій контур
* Polygonal (Полігональні) — Жовтий контур
* Unknown (Невідома форма або артефакт) — Білий контур

Клітини з площею менше 50 пікселів ігноруються як шумові артефакти.

## Встановлення залежностей

Для роботи скрипта потрібно встановити необхідні бібліотеки з файлу requirements.txt. Виконайте в терміналі:
```
pip install -r requirements.txt
```

## Використання

1. Відкрийте файл зі скриптом.
2. У блоці `if __name__ == "__main__"`: знайдіть змінну `p`. Вона відповідає за номер папки з результатами.
3. За необхідності змініть шляхи до файлів `IMAGE_FILE` та `MASK_FILE`, щоб вони відповідали структурі вашого проєкту.
4. Змінна `LOGS` дозволяє виводити детальну статистику:
   - `LOGS = True` — виводить у консоль таблицю з метриками (ексцентриситет, солідність, круглість, співвідношення сторін) для кожної клітини.
   - `LOGS = False` — виводить лише загальний підсумок за кількістю знайдених форм.
5. Запустіть скрипт:
```
python CellShape.py
```

| Індекс (p) | Переважаюча форма клітин |
| --- | --- |
| 18 | Round (Круглі) |
| 47 | Polygonal (Полігональні) |
| 61 | Polygonal + Round |
| 62 | Polygonal + Round |
| 64 | Spindle-shaped (Веретеноподібні) |
| 65 | Round (Круглі) |
| 66 | Multi-branched (Багатогалузеві) |
| 68 | Multi-branched (Багатогалузеві) |
